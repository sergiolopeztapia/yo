# Mi espacio personal

Proyecto Vite con una página personal simple.

## Requisitos

- Node.js 18 o superior
- pnpm

## Desarrollo

```bash
pnpm install
pnpm dev
```

## Producción

```bash
pnpm build
pnpm preview
```

## Personalización rápida

Edita `src/App.jsx` para cambiar el nombre, el texto de presentación y el correo de contacto.
